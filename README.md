# 实时订单簿深度可视化与量化网格交易引擎

基于Vue 3 + FastAPI的量化交易工具，WebSocket行情推送、Canvas订单簿深度热力图、网格策略回测引擎。

## 目标用户
量化交易爱好者、金融工程学生、日交易员

## 技术栈
- 前端: Vue 3 + TypeScript + Vite + Pinia + Element Plus + ECharts
- 后端: Python FastAPI + NumPy + SQLite + WebSocket

## 核心功能
1. WebSocket实时行情推送：模拟股票tick级别数据流(买一/卖一/成交量/时间)
2. Canvas订单簿深度热力图：买卖盘口10档深度可视化，红绿双向柱状图
3. ECharts K线图+网格上下轨+持仓标记叠加渲染
4. 网格交易策略引擎：价格区间/网格数量/每格资金参数配置
5. 策略回测：逐笔模拟 + 持仓收益计算 + 夏普比率/最大回撤/胜率统计
6. 回测报告：收益率曲线、逐格成交记录、绩效指标汇总
7. 批量回测对比：一次性提交多组「下限/上限/网格数量/每格资金」组合，逐条列出收益率、最大回撤、夏普比率、成交笔数并排对照；支持多组勾选、按统计指标排序、选择与排序跨刷新保留（localStorage）；单组越界或与已有组合重复时仅指出并跳过该条，不影响整批

## 批量对比接口
- `POST /api/backtest`：原有单次回测入口，行为不变
- `POST /api/backtest/batch`：请求体 `{ "configs": [...] }`，返回 `results`（每组四指标 + 成交笔数）与 `skipped`（被跳过的批内序号 `index` 与原因，如越界、与第 N 条重复、格式非法），任何一条异常都不会导致整批失败
